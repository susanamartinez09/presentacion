 Portafolio Personal - Susana Martinez
Este es el repositorio de mi portafolio web personal, diseñado para mostrar mis habilidades, experiencia y proyectos como Tecnóloga en Infraestructura Informática con un enfoque en el desarrollo web (Front-End).

🌟 Características Principales
Diseño Responsivo e Intuitivo: Construido bajo principios de UI/UX intuitivo y diseño responsivo para garantizar una experiencia óptima en cualquier dispositivo.

Enfoque Front-End: Muestra proyectos que resaltan el dominio en tecnologías clave del lado del cliente.

Perfil Completo: Incluye una sección de resumen, habilidades (Mis Habilidades), enlace a CV (Descargar CV) y acceso directo a redes profesionales (LinkedIn).

Tecnologías Ágiles: Refleja la experiencia y el enfoque en metodologías ágiles para el desarrollo de proyectos.

🛠️ Tecnologías Utilizadas
Este proyecto fue desarrollado utilizando un sólido conjunto de tecnologías fundamentales para el desarrollo web:

HTML5: Estructura semántica del contenido.

CSS3: Estilos, diseño responsivo y presentación visual.

JavaScript (JS): Interactividad, manipulación del DOM y lógica Front-End.

PHP: Mencionado en la descripción, se asume su uso potencial para la gestión de formularios o el lado del servidor, aunque el enfoque principal del portafolio es Front-End.
